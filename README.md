# Pharmaceutical QMS Dashboard

I created this project to practice working with pharmaceutical quality data and improve my Excel and Tableau skills. The project uses 40 simulated quality records covering deviations, CAPAs, change controls, audit findings, and complaints.

All information in this project is simulated. It does not contain real company, manufacturing, or patient data.

## Dashboard

![Pharmaceutical QMS Dashboard](Pharmaceutical%20QMS%20Dashboard.png)

## What I Did

I organized the quality records in Excel and included details such as record type, department, risk level, root cause, assigned owner, due date, closure date, CAPA status, and overdue status.

I connected the Excel file to Tableau and created calculated fields to track important QMS measures. I also built KPI views and charts to understand the status of the records and identify patterns in the data.

## Project Results

- 40 total quality records
- 13 open records
- 27 closed records
- 23 overdue records
- 4 critical open records
- 38.04 average days to close a record

I also reviewed the records by type, risk level, department, root cause, and CAPA effectiveness.
